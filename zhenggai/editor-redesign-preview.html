Flowio 编辑器页面深度整改方案

针对截图区域填充/变形、最大化后页面变形、按钮排列不满等问题，逐一分析根因并提供前后对比方案。

!

问题根因深度分析

1. 截图区域填充/变形

根因：当前使用 aspect-ratio: 16/9 + max-height: 420px 固定容器，图片用 object-fit: contain 居中。
小截图 → 容器大，图片四周大量灰色填充区域，视觉丑陋。
宽截图 → 容器高度不够，被裁切或缩放变形。
无截图 → 灰色背景空荡荡。
方案：移除固定宽高比，改用 max-height: 55% 相对视口高度，object-fit: contain 让图片自适应。图片本身决定高度，容器仅做最大高度限制。小图居中显示，大图等比缩放不溢出。
/* 当前（问题代码） */
.step-detail-image {
  aspect-ratio: 16 / 9;
  max-height: 420px;
  background: #e8eaed;
}

/* 整改后 */
.step-detail-image {
  flex: 0 0 auto;
  max-height: 55%;
  min-height: 180px;
  background: #f9fafb;
  display: flex;
  align-items: center;
  justify-content: center;
}
.step-detail-image img {
  max-width: 100%;
  max-height: 100%;
  width: auto;
  height: auto;
  object-fit: contain;
}

2. 最大化后页面变形

根因：截图区域 max-height: 420px 是固定像素值，最大化窗口后图片被限制无法扩展。侧边栏 width: 320px 固定，主区域无法充分利用空间。同时 editor-preview-body 的 padding: 16px 40px 在宽屏下浪费大量空间。
方案：截图区域改用 max-height: 55%（相对视口），最大化时自动扩展。侧边栏改为 min-width: 280px + max-width: 35% 弹性范围。主区域 padding 缩小为 16px 24px，充分利用宽屏空间。
/* 当前 */
.editor-sidebar { width: 320px; min-width: 280px; }
.editor-preview-body { padding: 16px 40px; }

/* 整改后 */
.editor-sidebar {
  width: 300px;
  min-width: 260px;
  max-width: 35%;
}
.editor-preview-body { padding: 16px 24px; }

3. 按钮排列不饱满

根因：标题栏操作按钮过多（导出、发布、扫描脱敏、文本脱敏、AI生成、预览、全图/裁图），全部在一行内 flex-shrink: 0 不换行，空间不足时被截断或溢出。主编辑区的"保存修改"按钮单独一行，视觉上松散。
方案：标题栏按钮分组，次要用折叠菜单收纳（如脱敏/AI 移到"更多"下拉）。主编辑区按钮固定在底部 bar，与表单区域分离，使用 flex-wrap: wrap 自适应换行。
/* 标题栏按钮折叠 */
.titlebar-more-dropdown { position: relative; }
.titlebar-more-btn:hover + .dropdown,
.dropdown:hover { display: flex; }

/* 底部按钮栏 */
.step-detail-actions {
  display: flex;
  align-items: center;
  gap: 8px;
  flex-wrap: wrap;
  padding: 12px 24px;
  border-top: 1px solid var(--border);
}

4. 无截图占位区丑陋

根因：无截图时显示纯灰色背景 + 一个 SVG 图标，文字提示"点击或拖拽上传步骤截图"，颜色和样式与整体设计不协调，且区域固定高度导致空荡荡。
方案：无截图时使用虚线边框 + 更柔和背景色，图标更精致，文字区分主次。hover 时高亮橙色提示。高度自适应，不超过 200px。
.step-detail-no-image {
  border: 1px dashed #d1d5db;
  background: #f9fafb;
  min-height: 160px;
  max-height: 200px;
  transition: all 0.15s;
}
.step-detail-no-image:hover {
  border-color: var(--blue);
  background: #fff7ed;
}

修改文件：src/styles.css 和 src/pages/StepEditor.tsx
1. CSS 截图区域（替换原有 .step-detail-image 规则）
/* 移除固定宽高比，改为自适应容器 */ .step-detail-image { position: relative; width: 100%; flex: 0 0 auto; /* 不自伸缩 */ max-height: 55%; /* 相对视口高度，最大化时自动扩展 */ min-height: 180px; /* 最小高度保障 */ border: 1px solid var(--border); border-radius: var(--radius); overflow: hidden; background: #f9fafb; /* 更柔和的背景色 */ display: flex; align-items: center; justify-content: center; } .step-detail-image img { display: block; max-width: 100%; max-height: 100%; width: auto; /* 图片自身宽度 */ height: auto; /* 图片自身高度 */ object-fit: contain; } /* 无截图占位区 */ .step-detail-no-image { width: 100%; min-height: 160px; max-height: 200px; border: 1px dashed var(--border); border-radius: var(--radius); background: #f9fafb; display: flex; flex-direction: column; align-items: center; justify-content: center; gap: 8px; cursor: pointer; transition: all 0.15s; } .step-detail-no-image:hover { border-color: var(--blue); background: #fff7ed; }
2. 侧边栏弹性宽度（替换原有 .editor-sidebar 规则）
.editor-sidebar { width: 300px; min-width: 260px; max-width: 35%; /* 宽屏时不超过 35% */ border-right: 1px solid var(--border); display: flex; flex-direction: column; background: var(--bg-secondary); overflow-y: auto; } .editor-preview-body { flex: 1; min-height: 0; overflow-y: auto; display: flex; flex-direction: column; padding: 16px 24px; /* 缩小 padding */ }
3. 移除 useLayoutEffect 中的固定高度计算（StepEditor.tsx）
// 删除或注释掉以下代码（约第 309-322 行） /* useLayoutEffect(() => { const el = stepDetailImageRef.current; if (!el) return; const setHeight = () => { const w = el.clientWidth; if (w > 0) { el.style.height = `${Math.min(Math.max(w * 9 / 16, 200), 520)}px`; } }; setHeight(); const ro = new ResizeObserver(setHeight); ro.observe(el); return () => ro.disconnect(); }, []); */ // 图片高度由 CSS 的 max-height + object-fit 控制，不再需要 JS 强制固定宽高比
