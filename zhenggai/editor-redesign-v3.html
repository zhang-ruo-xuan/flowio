Flowio 编辑器深度整改方案 v3

基于你之前的反馈（截图区域固定、按钮不溢出、全局操作不混入步骤操作），重新设计。先分析问题根因，再展示完整方案，最后给出代码改动预览。

分析 当前编辑器核心问题
1
截图区域高度不固定，编辑区抖动
当前代码用 aspect-ratio: 16/9 + max-height: 420px + JavaScript ResizeObserver 动态计算高度。不同截图大小导致容器高度变化，下方的表单和保存按钮随之上下跳动，体验极差。最大化窗口时高度固定为 420px，更显突兀。
2
标题栏按钮过多，空间不足时溢出
当前标题栏塞了 8 个按钮：导出、发布、扫描脱敏、文本脱敏、AI 生成、预览、全图、裁图。窗口较小时按钮溢出或换行，部分按钮被截断不可见。
3
全局操作与单步骤操作混在一起
扫描脱敏、文本脱敏、AI 生成、全图/裁图统一切换 — 这些是全局操作（作用于整个教程），却和单步骤的保存、删除按钮混排在标题栏和步骤编辑区，逻辑混乱。
4
无截图时占位区丑陋
当前无截图时显示一个浅灰色区域，没有明确的引导提示，用户不知道该点击还是拖拽上传。

详解 四个核心改动

截图区域固定 360px 核心修复

flex: 0 0 360px 固定高度，不随截图大小变化。深色背景 #1a1d21 让截图更突出。图片用 object-fit: contain 等比居中，带阴影增强层次。最大化时上限 55vh，保障编辑区始终可见。

flex: 0 0 360pxmax-height: 55vhobject-fit: contain深色背景

按钮浮动在图片上 仅单步骤

上传、粘贴、删除、全图/裁图、标注 — 仅这 5 个单步骤操作浮动在图片四角。毛玻璃半透明背景，hover 加深。全局操作（脱敏、AI）留在标题栏"更多"菜单。

backdrop-filter: blur(10px)rgba(0,0,0,0.5)四角定位

标题栏精简 仅 4 个

导出、发布、预览 + 更多 ▼。扫描脱敏、文本脱敏、AI 生成、全局全图/裁图全部折叠到"更多"下拉菜单。标题栏不再拥挤，窗口缩放时不会溢出。

4 个主按钮更多折叠清爽 titlebar

编辑区稳定 不抖动

截图区域固定后，编辑区的标题、描述表单和保存按钮位置不再随截图变化。最大化/还原窗口或切换不同截图，编辑区纹丝不动。

不抖动稳定布局Ctrl+S 保存
