截图区域固定 360px

使用 flex: 0 0 360px 固定高度，不随截图大小变化。图片用 object-fit: contain 等比居中，深色背景让截图更突出。最大化窗口时最多 50vh 保障编辑区可见。

flex: 0 0 360px max-height: 50vh 深色背景 #1a1d21

所有按钮浮动在图片上

上传、粘贴、删除、全图/裁图、标注 — 这些单步骤操作改为半透明毛玻璃按钮浮动在截图四角。脱敏、AI 生成等全局操作保留在标题栏"更多"菜单中。页面不再有冗余按钮栏。

毛玻璃 backdrop-filter 四角定位 四角分组

编辑区完全稳定

截图区域固定高度后，编辑区的表单位置不再随截图变化。最大化/还原窗口或切换不同截图，编辑区纹丝不动，用户体验一致。

不抖动 稳定布局

标题栏精简

从 8 个按钮减到 4 个：导出、发布、预览、更多。全局操作（脱敏、AI 生成）折叠到"更多"下拉菜单，单步骤操作（上传、标注、全图/裁图）迁移到图片浮动按钮。

4 个主按钮 更多折叠 清爽 titlebar
