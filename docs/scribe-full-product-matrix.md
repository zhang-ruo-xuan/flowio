# Flowio 全面国产化 — 大而全战略计划

> 版本：v2.1 · 日期：2026-08-11
> 核心命题：不是 Scribe 中文版，而是覆盖 Scribe 全部产品能力 + 中国生态深度集成的"操作知识平台"
> 参照对象：Scribe 全线产品矩阵

---

## 零、Scribe 产品矩阵全景（对标基准）

在开始规划之前，先明确我们要对标和超越的对象到底长什么样。

### Scribe 现有产品矩阵

| 产品 | 平台 | 形态 | 核心能力 | 收费 |
|------|------|------|---------|------|
| **Chrome 扩展** | Chrome 浏览器 | 浏览器扩展 | 录制浏览器操作、DOM 感知、自动截图 | 免费 |
| **Desktop App** | Windows / macOS | 原生桌面应用 | 录制任意桌面应用、OS 级全局 Hook、全屏截图 | Pro 独占 |
| **Web Dashboard** | scribehow.com | Web 应用 | 文档管理、查看器、团队空间、Analytics | 全部可用 |
| **Pages** | Web 端 | 编辑器功能 | 多文档聚合、拖拽拼接为长页面 | Pro 可用 |
| **Team Workspace** | Web 端 | 团队协作 | 多人共享文档库、权限管理、品牌定制 | Pro Team / Enterprise |
| **Viewer** | Web 端 | 只读查看器 | 分享链接查看、嵌入 Confluence/Notion | 免费 |

### Scribe 没有的东西（我们的机会）

| Scribe 缺失 | 中国市场需求 | Flowio 策略 |
|------------|------------|------------|
| ❌ 没有移动端原生 App | 手机操作教程（小程序/App） | ✅ 微信小程序查看端 + 安卓录制端 |
| ❌ 不支持飞书/钉钉/企微 | 中国企业标配协作工具 | ✅ 深度嵌入三大平台 |
| ❌ 不支持微信生态 | 微信是中国核心分发渠道 | ✅ 微信长图/小程序/公众号矩阵 |
| ❌ 没有离线能力 | 政务/金融/军工场景刚需 | ✅ 全本地架构，离线完整可用 |
| ❌ 中文 AI 体验差 | 中文软件界面识别不准 | ✅ 中文 UI 术语库 + 国产大模型 |
| ❌ 没有 RPA 执行 | 知道怎么操作，还想自动执行 | ✅ 步骤一键回放执行 |

### 2.2 浏览器扩展（Flowio Extension）— 网页场景

**定位**：Scribe Chrome Extension 的国产化替代，覆盖所有网页操作录制场景。

**技术栈**：Chrome Extension Manifest V3 + TypeScript

#### 为什么必须做扩展

1. **Scribe 的核心就是扩展起家**：他们的 80% 用户入口是 Chrome 扩展
2. **网页场景不可替代**：录制 SaaS 后台、在线表单、网页配置页面，只有扩展能精准捕获 DOM 元素信息
3. **录制 → 编辑无缝衔接**：扩展录制完成后，一键推送到桌面端编辑器
4. **中国市场 Chrome Web Store 虽不可用，但 Edge 扩展商店可用**：优先上架 Microsoft Edge Add-ons

#### 功能版图

```
Flowio Extension
├── 弹出面板（Popup）
│   ├── 开始录制 / 停止录制
│   ├── 当前录制状态（步骤数 / 时长）
│   ├── 历史录制列表（最近 10 条）
│   └── 设置入口
│
├── 录制核心（Content Script + Background Worker）
│   ├── DOM 事件监听（click / input / change / focus）
│   ├── 元素信息提取（aria-label / text / CSS selector / XPath）
│   ├── 页面截图（chrome.tabs.captureVisibleTab）
│   ├── 元素高亮（录制时绿色边框指示当前捕获元素）
│   ├── 防抖去重（连续点击合并）
│   └── 页面跳转追踪（URL 变化 → 自动截图 Before/After）
│
├── 录制控件（Content Script UI）
│   ├── 页面右下角浮动红点（最小化干扰）
│   ├── 点击展开 → Pause / Complete / Delete
│   └── 当前步骤数实时显示
│
├── AI 生成
│   ├── 录制完成后 → 发送到桌面端 AI 引擎处理
│   └── 或 → 直接调用云端 AI（轻量模式，无需桌面端）
│
├── 数据同步
│   ├── 保存到浏览器本地存储
│   ├── 一键推送到桌面端编辑器（通过 Native Messaging 或 WebSocket）
│   └── 可选同步到 Flowio Cloud
│
└── 兼容性
    ├── Chrome / Edge / 360 极速 / QQ 浏览器（Chromium 内核）
    └── Microsoft Edge Add-ons 商店上架
```

#### 与 Scribe 扩展的差异化

| Scribe Extension | Flowio Extension |
|-----------------|------------------|
| 仅英文界面 | 中文优先 |
| 依赖 Google 服务 | 无 Google 依赖，纯本地 |
| AI 云端生成 | 可选本地桌面端 AI 或云端 AI |
| 导出到 Confluence/Notion | 导出到飞书/钉钉/企微 |
| 仅 Chrome | Chrome + Edge + 国产 Chromium 浏览器 |

### 2.4 移动端（Flowio Mini Program）— 消费 + 轻量生产

**定位**：Scribe 完全没有移动端，这是 Flowio 的蓝海。

**策略**：不做重型 App，而是"微信小程序查看端" + "安卓 App 教程录制"。

#### 为什么不做重型 iOS/Android App

Scribe 没有移动端是有原因的：
- 手机屏幕太小，不适合编辑操作指南
- 录制手机操作需要系统级权限，iOS 基本不可能
- 用户主要消费场景是"看"，不是"做"

所以 Flowio 移动端的策略是**轻量化**：

```
Flowio 移动端
├── 微信小程序（P0）
│   ├── 扫码查看分享链接
│   ├── Before → After 步骤展示
│   ├── 收藏 / 转发到微信群
│   ├── 搜索公开教程
│   └── 个人中心（我的收藏/浏览记录）
│
└── 安卓 App 教程录制（P2，未来探索）
    ├── AccessibilityService 录制安卓操作
    ├── 截图 + 步骤生成
    └── 同步到桌面端编辑
```

#### 小程序的核心价值

- **微信内闭环分享**：桌面录制 → 生成长图/小程序链接 → 发微信群 → 对方点开即看
- **社交裂变**：优质教程天然适合转发
- **零安装成本**：扫码即用，无需下载 App

### 不做什么（同样重要）

- ❌ 不做 Mac 版：Tauri 天然跨平台但别分心，Windows 占有率 70%+，先吃透
- ❌ 不做移动端：操作录制天然桌面场景，手机录屏有系统自带方案
- ❌ 不做钉钉首发：钉钉审核最严、生态最封闭，飞书先跑通再适配
- ❌ 不追求"全自动 AI"：现阶段 AI 辅助标注比全自动更可靠，别在产品不成熟时吹 AI
- ❌ 不急着做国际化：Product Hunt 走一波够，真正的多语言+海外获客放到阶段 7 之后
