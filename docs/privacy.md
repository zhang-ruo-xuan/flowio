# 隐私政策

**最后更新：2026-07-26**

录步 Flowio（以下简称「本软件」）重视您的隐私。本隐私政策说明我们如何处理您的数据。

## 数据收集与存储

- **本地存储**：所有录制的操作步骤、截图、AI 生成内容均存储于您的本地设备，不会自动上传至任何云端服务器。
- **API Key**：您自行配置的 API Key（智谱/DeepSeek/通义千问/OpenAI 等）通过 Windows 凭据管理器加密存储，仅在本机使用。
- **AI 调用**：使用 AI 生成操作指南时，步骤描述和截图会发送至您选择的 AI 服务商（如智谱 GLM）进行处理。请参阅各服务商的隐私政策。
- **无遥测**：本软件不包含任何遥测、用户行为追踪或分析 SDK。

## 数据安全

- 截图文件存储在系统临时目录，可随时清理。
- API Key 使用操作系统级加密存储（Windows Credential Manager），不以明文落盘。

## 您的权利

您可以随时：
- 删除本地截图和录制数据
- 通过设置面板移除已保存的 API Key
- 卸载软件以清除所有关联数据
