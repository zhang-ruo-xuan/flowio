# ADR-004：本地优先数据策略

> 状态：已采纳
> 日期：2026-07-25
> 决策者：录步 (Flowio) 项目

## 背景

录步的录制功能会捕获用户的屏幕操作数据（点击位置、输入文本、应用名称、截图）。这些数据具有高度隐私敏感性：

- 可能包含企业内部系统界面、客户信息
- 键盘输入可能涉及密码、账号（虽然有密码字段过滤机制）
- 截图可能包含敏感业务数据

同时，云端同步涉及服务器成本和数据合规问题。MVP 阶段团队资源有限，不适合投入后端基础设施。

## 决策

**本地优先数据策略：所有录制数据默认存储在用户本地，不上传任何服务器。**

具体规则：

| 数据类型 | 存储方式 | 位置 | 加密 |
|----------|----------|------|------|
| 录制项目 + 步骤 | SQLite | 用户指定目录（默认 `%APPDATA%/Flowio/`） | 否 |
| 截图文件 | JPEG 文件 | SQLite 同目录下的 `screenshots/` | 否 |
| API Key | Tauri keyring | Windows Credential Manager | ✅ 系统级加密 |
| 应用设置 (KV) | tauri-plugin-store | `%APPDATA%/Flowio/settings.json` | 否 |

**关键保护措施**：
- 密码字段：UI Automation 检测 `IsPasswordProperty`，值替换为 `[密码]`
- 敏感信息过滤：AI 调用前扫描身份证号/手机号/银行卡号，替换为 `[已隐藏]`
- 截图不含 EXIF 元数据
- 录步自身窗口的操作自动过滤，不录制

## 理由

1. **隐私合规**：GDPR / 《个人信息保护法》要求最小化数据收集，本地存储天然合规
2. **用户信任**：不传数据到服务器 = 用户完全掌控自己的数据，消除隐私顾虑
3. **零服务器成本**：MVP 阶段无后端，无需承担存储/带宽费用
4. **安全架构简单**：无数据传输 → 无传输加密 → 无服务器漏洞风险
5. **API Key 系统级保护**：Windows Credential Manager 是操作系统级安全存储，比文件加密更可靠

## 后果

- **正面**：用户隐私保护强，信任度高；零后端成本；安全架构简单
- **负面**：
  - 不支持云端同步——用户换电脑后无法访问历史录制（V1.0 前）
  - 无法跨设备协作——团队版需求（V2.0）
  - 分享链接功能受限——MVP 中只能导出文件，无法生成在线链接（F05 预留 UI + 引导文案）
- **缓解**：V1.0 评估引入可选的云端同步（用户主动授权后上传）；导出功能（PDF/HTML/MD）可在本地产出文件后通过邮件/IM 分享
