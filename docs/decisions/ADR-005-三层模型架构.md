# ADR-005：三层模型架构

> 状态：已采纳
> 日期：2026-07-25
> 决策者：录步 (Flowio) 项目

## 背景

在确定默认模型为智谱 GLM-4-flash（ADR-001）后，仍需解决以下问题：

1. **用户多样性**：高级用户可能偏好其他模型（如 DeepSeek 代码能力更强、通义千问在某些场景更准确）
2. **成本灵活性**：部分用户愿意使用自己的 API Key 以换取无限制调用
3. **国际化预留**：未来可能面向海外用户，需要接入 OpenAI/Claude
4. **风险对冲**：单一模型依赖存在服务中断风险

同时，录步的产品定位是「国产化工具」，模型选择应体现国产优先导向。

## 决策

**采用三层模型架构**，按优先级从高到低排列：

| 层级 | 角色 | 模型 | MVP 状态 | 计费方式 |
|------|------|------|----------|----------|
| 第一层 | 默认内置 | 智谱 GLM-4-flash | ✅ MVP 实现 | 包含在订阅费 |
| 第二层 | 国产可配 | DeepSeek V4 / 通义千问 / 其他国产 | 🔜 V1.0 | 用户自配 API Key |
| 第三层 | 国外垫后 | OpenAI / Claude | 🔜 V1.0 | 用户自配 API Key |

**核心规则**：
- MVP 阶段**只实现第一层**，第二、三层在设置页面显示但不可选，标注「即将上线」
- 用户自配 Key 后 AI 调用不计入我们的额度，无调用次数限制
- 模型选择 UI 严格按层级顺序排列：默认置顶 → 国产中间 → 国外垫底
- 所有模型 API 均为 OpenAI 兼容格式，切换只改 endpoint + model ID

## 理由

1. **默认低成本合规**：智谱 GLM-4-flash ¥0.02/次，订阅费毛利健康；国产合规无数据出境风险
2. **高级用户有选择权**：自配 Key 通道满足技术用户对模型自由度的需求，同时我们零边际成本
3. **国产优先**：符合信创政策导向，第二层全部为国产模型，第三层仅作为兜底选项
4. **风险对冲**：第一层故障时，用户可自行切换到第二层，避免单点故障
5. **技术实现简单**：OpenAI 兼容格式意味着 `AIModelProvider` trait 只需配置 endpoint + model ID + API Key 来源

## 后果

- **正面**：用户选择权充分，架构灵活可扩展；国产优先定位清晰；风险分散
- **负面**：设置页面需分层展示，UI 复杂度增加；第二/三层模型需单独测试兼容性
- **缓解**：设置页面采用分组设计（"内置模型" / "自定义模型"），视觉层次清晰；OpenAI 兼容格式天然保证切换兼容性
- **待跟进**：第二/三层模型接入时间点（计划 V1.0）；需编写用户引导文档「如何获取各平台 API Key」
