# Flowio Desktop 工具版 UI 规范

> 版本：v1.0 · 日期：2026-08-01
> 双核心驱动：**模仿 Scribe 桌面版视觉语言 + 国产化中文体验优化**

---

## 一、设计原则

| 原则 | Scribe 继承 | 国产化适配 |
|------|:----------:|:--------:|
| 极简克制 | Scribe 大面积留白、无边框卡片 | 中文用户偏好"一眼看全"，信息密度略提升 |
| 品牌色系 | 蓝色主调 + 橙色强调 | 蓝色沿用（国内工具普遍蓝），橙色保留 |
| 字体体系 | Inter 西文 | 思源黑体 / HarmonyOS Sans 中文 |
| 圆角系统 | 8px 统一圆角 | 10px（国内偏好更圆润） |
| 暗色模式 | Scribe 无暗色 | 增加暗色（国内工程师用户刚需） |
| 交互范式 | 悬停浮现操作 | 保留 + 增加长按右键操作 |

## 三、字体体系

### 3.1 西文

```
Inter (v4.0)
├── 标题:     Inter SemiBold  600
├── 正文:     Inter Regular   400
├── 小字:     Inter Medium    500（操作按钮等）
└── 等宽:     JetBrains Mono  （设置中输入框/代码块）
```

### 3.2 中文（国产化核心）

```
字体栈: "HarmonyOS Sans SC", "思源黑体", "PingFang SC", 
        "Microsoft YaHei", sans-serif

优先级: HarmonyOS Sans > 思源黑体 > 苹方 > 微软雅黑
选择理由: 
  • HarmonyOS Sans / 思源黑体 — 无版权风险，显示质量好
  • 苹方 — macOS 默认中文，覆盖 Mac 用户
  • 微软雅黑 — Windows 兜底，保证不丢字
```

### 3.3 字号阶梯

| 层级 | 大小 | 字重 | 用途 |
|------|:---:|:---:|------|
| H1 | 28px | 600 | 编辑器标题 |
| H2 | 20px | 600 | Dashboard 录制标题 |
| H3 | 16px | 600 | 步骤标题、面板标题 |
| Body | 14px | 400 | 正文、描述 |
| Body-S | 13px | 400 | 辅助说明、时间戳 |
| Caption | 12px | 500 | 步骤编号、标签 |
| XS | 11px | 400 | 快捷键展示、极小备注 |

## 四、间距与圆角

```
间距系统（4px 基准）
   4px   8px   12px   16px   20px   24px   32px   48px
   xs     sm     md     lg     xl    2xl   3xl    4xl

圆角系统
   6px   8px   10px   12px   9999px
   小按钮 卡片   输入框  弹窗    Pill标签/圆形头像

Scribe 用 8px 统一圆角 → 国产化提升至 10px，更圆润亲和
步骤序号球用 9999px（正圆），与 Scribe 一致
```
