## 风险关注点

1. **录制引擎稳定性**：Win32 Hook 在某些系统环境下可能被安全软件拦截，导致录制事件丢失
2. **AI 生成网络依赖**：网络不稳定时 AI 调用可能超时失败，需验证重试机制
3. **截图内存管理**：16 帧环形缓冲 + JPEG 压缩，长时间录制需关注内存不泄漏
4. **WebView 重建**：Tauri WebView 在某些情况下会重建（如系统资源不足），录制状态需可靠恢复
5. **密码字段检测准确性**：UIA PasswordMask 检测可能漏掉某些自定义密码框
6. **多显示器场景**：多显示器环境下截图和坐标可能异常
