## 第 1 章：产品概述

### 1.1 产品定义

| 属性 | 内容 |
|------|------|
| 产品名称 | 录步 |
| 英文名 | Flowio |
| 一句话定位 | 国产化流程文档工具，自动录制操作 → AI 生成中文步骤说明 → 导出/分享 |
| 对标产品 | Scribe（估值 $13 亿，ARR $1 亿，600 万+用户） |
| 目标平台 | Windows 10/11（MVP），macOS（V1.0） |
| 技术栈 | Tauri 2 + Rust + React + TypeScript + Tailwind CSS |
| AI 默认模型 | 智谱 GLM-4-flash（备选：DeepSeek V4、通义千问） |
| 商业模式 | 免费版引流 + ¥29/月个人版 + ¥79/seat/月团队版 |

### 1.2 核心价值主张

```
用户操作电脑  →  录步自动捕获（点击/输入/截图/元素识别）
              →  AI 生成中文步骤说明（标题 + 文字描述 + 截图标注）
              →  一键导出/分享（PDF / HTML / Markdown / 链接）
```

录步解决的核心问题：**将"手动截图+排版写文档"的耗时工作，缩短为"操作一遍即可生成"的秒级体验。**

### 1.3 差异化定位

根据 `market-research.md` 结论，录步的差异化战略为"三个国产化"：

| 维度 | Scribe（竞品） | 录步（差异化） |
|------|---------------|---------------|
| AI 模型 | OpenAI/自有 | 智谱/通义千问/DeepSeek（国产，数据不出境） |
| 语言体验 | 英文为主，中文翻译质量不稳定 | **中文原生**，AI 直接用中文生成步骤描述 |
| UI 设计 | 西式交互逻辑 | 国产化（类飞书/钉钉风格，符合国人操作习惯） |
| 桌面框架 | Electron（~200MB） | Tauri 2（~10MB，轻量 20 倍） |
| 定价 | $23/月（≈¥165） | **¥29/月**（性价比极高） |
| 合规 | 海外服务器 | 支持私有化部署，数据不出境 |

### 1.4 产品愿景与里程碑

#### MVP（当前阶段目标）

**完成时间**：阶段 0-4（项目初始化 → 产品设计 → UI/UX → 开发）

核心能力：**能录、能生成、能导出、能分享。**

- 屏幕操作录制（点击/输入/滚动，自动截图）
- AI 生成中文步骤说明（调用智谱 GLM-4-flash）
- 步骤编辑（增删改、排序、合并拆分）
- 导出（PDF / HTML / Markdown）
- 分享链接生成
- 基础设置（AI 模型切换、API Key 自定义）

#### V1.0（功能完善）

**完成时间**：MVP 发布后 3-6 个月

- 浏览器录制（Chrome/Edge 扩展）
- macOS 支持
- 品牌定制（Logo、颜色、页眉页脚）
- 截图编辑（裁剪、标注、箭头、文字）
- OCR 文本识别（中英文）
- 自动更新机制

#### V2.0（商业化）

**完成时间**：V1.0 后 6-12 个月

- 支付系统接入（支付宝/微信支付）
- 团队协作（共享空间、评论、审批）
- 模板市场（SOP 模板、行业模板）
- 多语言翻译（一键翻译步骤为英文/日文）
- 数据看板（使用统计、团队活跃度）
- SSO 企业登录集成
- 私有化部署方案

## 第 3 章：核心功能

### 3.1 P0 功能（MVP 必须实现）

#### F01 — 屏幕操作录制

**功能描述**：通过全局快捷键（默认 Ctrl+Alt+R）启动/停止录制。录制期间自动捕获用户的鼠标点击、键盘输入、滚轮操作，并对每次操作自动截图。

**技术基础**：复用 StepSnap 的 `recorder.rs`（rdev 全局事件监听 + xcap 截图 + UI Automation 元素识别）。

**用户故事**：作为用户，我希望按下快捷键就能开始录制我的屏幕操作，以便将操作过程自动转化为步骤文档。

**验收条件**：
- 按下 Ctrl+Alt+R 开始录制，再次按下停止录制
- 录制期间，鼠标每次点击（左键/右键）自动截图并记录坐标
- 键盘输入自动捕获文本内容
- 滚轮操作被记录（滚动方向+距离）
- 录制状态有明确视觉反馈（系统托盘图标变化 + 悬浮指示器）
- 窗口切换时自动记录宿主应用名称
- 密码字段自动识别并替换为 `[密码]`
- 录制期间不录制录步自身窗口的操作
- 单次录制最多支持 200 步，超出时提示并自动停止

---

#### F02 — AI 生成中文步骤说明

**功能描述**：录制完成后，将步骤数据（截图 + 操作类型 + 元素名称 + 输入文本）发送给智谱 GLM-4-flash，由大模型生成中文步骤说明（每步包含：步骤标题 + 详细描述 + 截图）。

**技术基础**：`src/lib/aiService.ts`，OpenAI 兼容格式调用智谱 API。

**用户故事**：作为用户，我希望录制完成后自动生成带中文说明的步骤文档，以便无需手动编写每步描述。

**验收条件**：
- 录制停止后，自动触发 AI 生成流程，显示进度（"正在生成第 3/15 步..."）
- 每步生成中文标题（≤20 字）和详细描述（≤100 字）
- 生成内容包含操作对象名称（如"点击「保存」按钮"而非"点击按钮"）
- 整体生成时间：15 步以内 ≤ 10 秒，15-50 步 ≤ 30 秒，50-100 步 ≤ 60 秒
- 支持流式输出，用户可实时看到 AI 生成内容
- AI 调用失败时自动重试（最多 3 次），失败后提示用户并提供手动编辑入口
- 默认使用智谱 GLM-4-flash，可在设置中切换 DeepSeek V4 / 通义千问

---

#### F03 — 步骤编辑

**功能描述**：在 AI 生成步骤后，用户可以在编辑器中对步骤进行增删改、合并拆分、重新排序。

**用户故事**：作为用户，我希望能够手动编辑 AI 生成的步骤，以便修正不准确的内容或补充额外信息。

**验收条件**：
- 支持编辑单个步骤的标题和描述（点击进入编辑模式）
- 支持删除单个步骤（含确认提示）
- 支持在指定位置插入新步骤（手动上传截图+输入文字）
- 支持合并相邻步骤（将两步合并为一步，自动拼接描述）
- 支持拆分步骤（将一步拆为两步，用户分别编辑）
- 支持拖拽调整步骤顺序
- 支持撤销/重做（Ctrl+Z / Ctrl+Y，至少 20 步历史）
- 编辑操作即时保存到本地（SQLite），无需手动保存
- 「AI 重新生成」按钮：可针对单步让 AI 重新生成描述

---

#### F04 — 导出

**功能描述**：将编辑完成的步骤文档导出为多种格式。

**用户故事**：作为用户，我希望将步骤文档导出为常见格式，以便分享给同事或打印使用。

**验收条件**：
- 支持导出 PDF（含截图、标题、描述，A4 排版）
- 支持导出 HTML（独立文件，可直接在浏览器打开）
- 支持导出 Markdown（含图片 base64 内嵌）
- 导出时可选择包含/排除截图
- 导出文件名默认为"录步文档-{日期}-{标题}"
- 导出操作 ≤ 5 秒（50 步以内）
- PDF 导出的中文不乱码（嵌入中文字体）
- HTML 导出支持响应式布局

---

#### F05 — 分享链接生成（预留接口）

**功能描述**：生成一个可分享的网页链接，接收方可在浏览器中查看步骤文档。

**MVP 策略**：MVP 阶段预留 UI 入口和数据结构，实际云端存储和分享链接生成功能在 V1.0 实现。MVP 中点击分享时提示"分享功能将在 V1.0 上线，当前请使用导出功能"。

**用户故事**：作为用户，我希望生成一个链接直接分享给同事查看，以便对方无需安装软件即可阅读步骤文档。

**验收条件（MVP）**：
- 工具栏中有「分享」按钮
- 点击后显示提示文案，引导用户使用导出功能
- UI 和交互逻辑就绪，后续只需接入后端即可启用

---

#### F06 — 基础设置

**功能描述**：提供应用设置页面，允许用户配置 AI 模型、API Key、语言等。

**用户故事**：作为用户，我希望能够切换 AI 模型或使用自己的 API Key，以便控制 AI 成本和生成质量。

**验收条件**：
- 设置入口：系统托盘右键菜单 →「设置」或主界面设置图标
- AI 模型设置：
  - 默认选项：智谱 GLM-4-flash / DeepSeek V4 / 通义千问
  - 每个选项显示简要说明和预估成本
- API Key 自定义：
  - 提供输入框，用户可填入自己的 API Key
  - API Key 存储使用 Tauri keyring（加密本地存储）
  - 提供「测试连接」按钮验证 API Key 是否有效
  - 提供引导链接：如何获取智谱/DeepSeek/通义千问的 API Key
- 原 AI 额度提示：显示当前套餐 AI 调用剩余次数
- 语言设置：中文（默认），英文预留选项
- 录制快捷键自定义：允许用户修改开始/停止录制的快捷键
- 数据目录设置：允许用户修改录制数据存储位置

## 第 4 章：非功能需求

### 4.1 性能需求

| 指标 | 目标值 | 测量方法 |
|------|--------|----------|
| 录制对系统的影响 | CPU 占用 ≤ 5%，内存增量 ≤ 100MB | 任务管理器监控 |
| 截图延迟 | 每次截图 ≤ 200ms | 代码计时 |
| AI 生成步骤（15 步） | ≤ 10 秒 | 端到端计时 |
| AI 生成步骤（50 步） | ≤ 30 秒 | 端到端计时 |
| AI 生成步骤（100 步） | ≤ 60 秒 | 端到端计时 |
| 导出 PDF（50 步） | ≤ 5 秒 | 端到端计时 |
| 应用启动时间 | ≤ 3 秒（冷启动），≤ 1 秒（热启动） | 秒表计时 |
| 安装包大小 | ≤ 15MB（Windows .msi） | 文件属性 |

### 4.2 安全需求

| 需求 | 实现方式 |
|------|----------|
| API Key 安全存储 | 使用 Tauri keyring（操作系统级加密存储），不存明文 |
| 录制数据本地优先 | 所有录制数据默认存储在本地 SQLite 数据库 |
| 密码字段保护 | 通过 UI Automation 检测 password/secure 字段，值替换为 `[密码]` |
| 敏感信息不上传 | AI 调用前过滤步骤中的敏感模式（身份证号、手机号、银行卡号） |
| 应用自身安全 | 代码签名（Windows Authenticode），防止篡改 |

### 4.3 兼容性需求

| 平台 | 版本 | MVP 支持 | 备注 |
|------|------|----------|------|
| Windows | 10（21H2+） | ✅ | 主要目标平台 |
| Windows | 11 | ✅ | 完全支持 |
| macOS | 14 Sonoma+ | ❌（V1.0） | 需适配 Accessibility API |
| Linux | Ubuntu 22.04+ | ❌ | 后续评估 |

### 4.4 可用性需求

| 需求 | 具体要求 |
|------|----------|
| 中文界面 | 所有 UI 文本、提示、错误信息使用简体中文 |
| 错误提示友好 | 网络错误/API 错误给出具体原因和建议操作（而非堆栈信息） |
| 键盘导航 | 核心功能（开始录制/停止录制/导出）支持纯键盘操作 |
| 首次引导 | 首次启动显示 3 步引导：开始录制 → 查看步骤 → 导出分享 |
| 空状态处理 | 无录制记录时显示引导提示，非空白页面 |
| 加载状态 | AI 生成/导出过程中显示进度，不可操作时禁用按钮 |

### 4.5 可维护性需求

| 需求 | 具体要求 |
|------|----------|
| 代码规范 | 严格遵守 `AGENTS.md` 的 TypeScript/Rust 规范 |
| 模块化架构 | 录制引擎/ AI 服务/导出引擎/存储层 解耦，各自独立 |
| 编译验证 | 每次提交前 `pnpm build && cargo build` 必须通过 |
| 错误日志 | 关键模块使用 Tauri 日志插件，支持分级（info/warn/error） |
| 文档同步 | spec.md / plan.md / tasks.md 随代码同步更新 |

## 第 5 章：不做的事情（范围边界）

以下功能**明确不在 MVP 范围内**，防止开发过程中范围蔓延：
