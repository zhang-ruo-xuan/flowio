# Flowio 国产化路径 — 全面实施计划

> 基于 `scribe-deep-analysis.md` 第 10-11 章，将分析结论落地为可执行的工程计划。
> 核心命题：不是做"Scribe 中文版"，而是打造"比 Scribe 更懂中国人的操作录制工具"。

---

## 总览：四阶段路线图

```
Phase 1 ──────── Phase 2 ──────── Phase 3 ──────── Phase 4
国产化基础        中国生态集成        企业商业化          平台化
2026.Q3           2026.Q4            2027.H1             2027.H2+
────────────────────────────────────────────────────────────────→
用户量: 种子 100      内测 1000+        付费用户 100+ 企业   规模化
```

| 阶段 | 周期 | 目标 | 核心交付 |
|------|------|------|---------|
| Phase 1 | 当前 → 2026.Q3 | 打磨产品基本功，对齐 Scribe 桌面版体验 | 编辑器重写、AI 中文优化、基础分享 |
| Phase 2 | 2026.Q4 | 接入中国互联网生态，具备分发能力 | 微信/飞书/钉钉集成、支付、登录 |
| Phase 3 | 2027.H1 | 企业级商业化，形成收入 | 团队版、私有化部署、SSO、等保 |
| Phase 4 | 2027.H2+ | 平台化，定义品类 | 知识库平台、小程序端、ISV 生态 |

## Phase 1：国产化基础（当前 → 2026.Q3）

> **目标**：让 Flowio 在核心体验上达到 Scribe 桌面版水准，并在中文场景超越它。

### 1.2 中文步骤生成 Prompt 优化

**当前状态**：规则式禁则 Prompt（"绝对禁止出现坐标"、"禁止使用含技术细节的描述"），以负向约束为主。
**目标状态**：正向引导式 Prompt，告诉 AI 应该生成什么风格的中文操作描述，适配国产大模型（智谱 GLM-4-flash / DeepSeek-V4）。

#### Prompt 改造策略

| 维度 | 当前（规则式） | 目标（引导式） |
|------|-------------|-------------|
| 系统提示 | "你需要从技术描述中提炼业务描述" | "你是一位中文操作指南撰写专家。你的风格：简洁、准确、动词优先。" |
| 描述风格 | 禁止列表（7条"绝对禁止"） | 正向示例（给出3-5个优秀描述示例，让模型模仿） |
| 按钮名提取 | `element_info.name` 直出 | 结合截图 OCR 校验，修正 AI 可能识别错误的按钮名 |
| 中文 UI 术语 | 未做特殊处理 | 预制常见中文 UI 术语词表（登录/注册/提交/保存/确认/取消） |
| 截图理解 | 纯文字 Prompt（无截图） | 增加截图内容描述字段，辅助 AI 生成更准确的步骤说明 |

#### 涉及的源码文件

| 文件 | 操作 | 说明 |
|------|------|------|
| `src-tauri/src/ai_pipeline/prompt_template.rs` | 重写 | 正向引导式 Prompt |
| `src-tauri/src/ai_pipeline/step_parser.rs` | 增强 | 增加中文 UI 术语匹配 |
| `src-tauri/src/ai_pipeline/client.rs` | 检查 | 确认多模型支持（GLM-4-flash / DeepSeek） |

#### 新 Prompt 核心框架

```
系统提示词（正向引导）：

你是一位中文操作指南撰写专家，擅长将屏幕操作转化为简洁易懂的步骤说明。

撰写风格要求：
1. 使用动宾短语开头（如"点击"、"输入"、"选择"、"拖拽"）
2. 步骤描述不超过 20 个字
3. 引用的按钮/菜单名称使用原文加引号（如"提交申请"按钮）
4. 不使用坐标、像素、DOM 等技术术语
5. 面向非技术用户，让完全没操作过该软件的人也能看懂

示例（优秀描述）：
- 点击"登录"按钮
- 在"用户名"输入框中输入工号
- 从下拉菜单中选择"增值税专用发票"
- 勾选"我同意用户协议"

示例（不合格描述）：
- 用户点击了页面右上角的蓝色按钮  ← 太啰嗦
- Click on the login button       ← 未中文化
- 在坐标(320, 450)处单击          ← 包含坐标
```

#### 验收标准

- [ ] AI 生成的步骤描述不再出现坐标信息
- [ ] 按钮名称与截图中实际文字一致
- [ ] 中文描述流畅自然，非机翻风格
- [ ] 用 3 个真实录制场景测试通过（ERP 操作 / 网页表单 / 政务系统）

### 1.3 基础分享功能实现

**当前状态**：`share.rs` 完全空壳，`start()` 直接返回 `Err("share server not implemented")`。
**目标状态**：实现本地 HTTP 分享服务，支持生成分享链接和本地导出。

#### 实现方案

```
┌──────────────────────────────────────┐
│            Flowio 桌面端              │
│                                      │
│  ┌────────────┐    ┌──────────────┐  │
│  │  编辑器     │───→│  ShareServer │  │
│  │  点击分享   │    │  (Rust)      │  │
│  └────────────┘    │              │  │
│                    │  localhost:   │  │
│                    │  随机端口     │  │
│                    │              │  │
│                    │  ┌─────────┐ │  │
│                    │  │ 静态HTML │ │  │
│                    │  │ 查看器    │ │  │
│                    │  └─────────┘ │  │
│                    └──────┬───────┘  │
│                           │          │
└───────────────────────────┼──────────┘
                            │
                    ┌───────▼───────┐
                    │  局域网内其他   │
                    │  设备浏览器    │
                    │  查看分享链接   │
                    └───────────────┘
```

#### 功能清单

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 启动 HTTP 服务 | P0 | `localhost:随机端口`，提供只读查看器 |
| 生成分享链接 | P0 | 返回 `http://局域网IP:端口/s/随机ID` |
| HTML 查看器 | P0 | 与编辑器同布局但只读，展示 Before+After 截图 |
| 链接复制到剪贴板 | P1 | 前端一键复制 |
| 停止分享 | P1 | 关闭 HTTP 服务 |
| 密码保护 | P2 | 简单密码验证 |
| QR 码生成 | P2 | 手机扫码查看 |

#### 技术选型

| 组件 | 方案 | 理由 |
|------|------|------|
| HTTP 服务 | Rust `tiny_http` 或 `actix-web` | Tauri 原生集成，零额外依赖 |
| 查看器前端 | 复用编辑器 HTML 模板 | 只读模式，去除编辑功能 |
| 截图服务 | 本地文件路径映射 | 无需上传，安全、即时 |
| 链接格式 | `/s/{uuid}` | 不可猜测，安全性基础 |

#### 涉及的源码文件

| 文件 | 操作 | 说明 |
|------|------|------|
| `src-tauri/src/share.rs` | 完整实现 | HTTP 分享服务器 |
| `src-tauri/Cargo.toml` | 添加依赖 | `tiny_http` / `uuid` |
| `src/utils/export.ts` | 增强 | 新增微信长图导出 |

#### 验收标准

- [ ] 点击"分享"后在本地启动 HTTP 服务
- [ ] 生成可访问的分享链接
- [ ] 局域网内其他设备可打开查看器
- [ ] 查看器展示所有步骤的 Before+After 截图
- [ ] 停止分享后服务关闭
- [ ] 无内存泄漏（多次启停）
